# 通话页视觉改版

视觉改版最初独立保留在 `codex/voip-call-ui`／`mobile-voip-ui`，避免影响同期真机 VoIP 联调。2026-11-17 按用户要求将通话页、功能内组件、图标及生成脚本一并集成到 `feat/nuwa-basic-2026.11-voip-calls`，与 Android 来电分类／铃声修补共同交付。原 UI 工作树内容保留。

## 界面

- 采用常见电话界面的深色背景、居中圆角头像、姓名和独立状态区域；未取得头像时继续使用姓名首字，不增加查询接口。
- 语音通话底部为静音、大号红色挂断、音频输出；静音及扬声器选中后切换白底深色图标。
- 来电突出拒接和绿色接听；视频来电保留语音接听与视频接听两个现有操作。
- 视频画面铺满背景，保留原生远端与本机视频绑定，本机为右上小窗；操作区有渐变遮罩。
- 保留最小化、连接/重连、权限提示、音频中断、结束原因和设置入口；不新增未经验证的通话质量或加密提示。
- 沿用现有四种语言的文案键及两行截断样式，顶部和底部留出安全区。

## 修改边界

| 位置 | 内容 |
| --- | --- |
| `features/voip/screens/call.uvue` | 通话页模板、展示状态和布局样式 |
| `features/voip/components/call-control.uvue` | 功能内部的圆形图标按钮，仅转发点击 |
| `static/voip/call-icons` | 跨平台 PNG 线性图标，避免依赖系统 emoji 或新增全局字体 |
| `scripts/voip-ui/generate-call-icons.swift` | 使用系统 AppKit 从矢量路径重复生成图标 |

本 UI 改造没有修改 CallManager、状态机、接口、推送、RTC、原生系统来电页面或系统设置；视频挂载条件、现有操作函数体及调用目标保持不变。同期 Android 原生锁屏来电及铃声修补见 [验收记录](voip-acceptance.md)，与页面展示改动分开记录。

## 验证与接入

已用 ego-browser 对当前 uvue 模板生成的隔离预览检查 320/390/430px、语音/视频和六种状态，共 36 种组合；模拟按钮不连接真实服务。SFC/UTS 语法解析、原有 10 个操作函数体比对及 `git diff --check` 已检查。预览资源位于本工作树忽略目录 `out/voip-ui-preview`。

集成后重新执行 VoIP Vitest，15 文件／107 项通过；另复核模板与 UTS 语法、原有操作函数和图标资源。以上结果只证明界面预览和代码边界，不能替代 uni-app x 原生布局、视频层级或真机通话验收。后续使用同一真实 App 验证安全区、按钮点击、音频输出选择、视频小窗和通话收尾。

本次按“提交现有代码和 UI”的范围完成集成，没有重新启动平台编译或安装。华为 19:00 锁屏来电通过所使用的 `185702` APK 尚不包含本 UI 改版，不能将该轮结果视为新版 UI 验收。生产配置与部署保持不动。
