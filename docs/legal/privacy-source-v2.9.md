#### 1.3 设备标识符与设备环境信息的收集与使用说明 🆕 本次新增 / 修订

> 为回应应用市场对设备标识符与设备环境信息的审核要求，我们就各平台设备标识符（Android 端的 Android ID，HarmonyOS 端的 OAID、ODID、AAID 及其他设备标识符，iOS 端的 IDFV）、MAC 地址与已安装应用列表的处理规则作出如下专项说明。本节内容与前述清单具有同等效力，且与第十一章「应用自身对设备标识符与设备环境信息的处理」表逐项对应。

**（1）我们读取哪些设备标识符。** 设备标识符是系统为设备或应用分配的一串字符，用于在同一台设备上区分应用实例或统计设备数量。它不是你的姓名、手机号或身份证号，单独使用时不能直接识别你的真实身份；但与账号信息结合时，可能成为可用于关联设备的标识符。不同系统提供的标识符不同，本应用读取的标识符如下：

* **Android ID（SSAID）：** 安卓系统为应用分配的 64 位十六进制字符串（系统内部名称 `Settings.Secure.ANDROID_ID`），用于在 Android 设备上区分应用实例。Android 8.0 及以上按应用签名密钥隔离，卸载重装或恢复出厂设置会使其变更。

* **OAID（开放匿名设备标识符）：** HarmonyOS 提供的设备级匿名标识符，同一设备上不同应用取到的值相同；受系统「应用跟踪」开关控制，该开关关闭时应用只能取得全零的无效值。我们仅将其用于安全风控与去标识化统计，**不用于广告投放**。

* **ODID（开发者级设备标识符）：** HarmonyOS 提供给同一开发者名下应用的标识符，同一设备上本公司名下多个应用取到的值相同。我们仅将其用于账号安全风控与故障归因，**不用于跨应用行为分析或用户画像**。

* **AAID（应用匿名标识符）：** HarmonyOS 为单次应用安装分配的匿名标识符，卸载重装后会变更，隐私属性最强。我们将其作为设备维度的统计与登录态辅助标识。

* **其他设备标识符（设备认证凭据等）：** 在 HarmonyOS 端，为校验设备完整性与运行环境，安全风控能力可能读取系统提供的设备认证凭据等标识信息。此类信息仅用于判断设备是否处于可信运行环境，不包含你的账号、密码或身份信息。

#### 1.4 扫码配网场景下位置与附近设备信息的收集与使用说明 🆕 本次新增

当你使用「扫码配网」为智能硬件配置网络时，App 需要借助手机的蓝牙与 Wi-Fi 能力发现附近的待配网设备，并把 Wi-Fi 网络信息下发给该设备。为此，App 仅在你主动进入配网功能后申请相应权限，并仅在配网过程中使用以下信息：

* **附近的设备（蓝牙扫描与连接、WLAN 扫描）** ：用于扫描附近处于待配网状态的设备并与其中你选定的设备建立蓝牙或 Wi-Fi 连接。扫描过程中我们可能获取到**附近设备的名称、MAC 地址、蓝牙广播信息与信号强度**，这些信息仅用于识别并连接你正在配置的那台设备。

* **位置信息（大致位置；部分系统版本下为精确位置）** ：Android 系统规定应用扫描 Wi-Fi 网络须持有位置权限（Android 13 起部分场景由「附近的设备」权限承担），因此我们在配网流程中会申请该权限，**仅用于完成 Wi-Fi 扫描与连接**，不用于定位你本人。

* **Wi-Fi 网络信息（SSID、BSSID）** ：配网时，App 会通过系统 WLAN 接口读取**当前所连网络的 SSID（Wi-Fi 网络名称）与 BSSID（该网络路由器的 MAC 地址）** ，用于在配网页面回显你当前所在的网络、确认目标网络可用，并把该网络配置下发给待配网设备；此外，接收消息推送时应用与个推推送 SDK 也会读取 SSID、BSSID 以判断网络类型与通道可用性（见 11.2）。上述信息**仅用于配网与推送通道判断，不用于定位你的位置、不用于记录行踪，也不用于广告与用户画像**。

* **Wi-Fi 网络名称与密码**：你在配网页面选择或输入的 Wi-Fi 名称与密码，仅用于通过蓝牙或局域网下发给待配网设备，我们不会将其上传至服务器留存。

**使用边界与承诺。** （1）上述位置与附近设备信息**仅在你主动使用配网功能期间获取，不用于记录、还原或分析你的行踪轨迹**，也不用于广告投放、用户画像或跨应用追踪；（2）我们不会在后台静默扫描附近的蓝牙或 Wi-Fi 设备，也不会将扫描结果用于配网以外的任何目的；（3）配网完成后即停止扫描，扫描结果不上传、不留存，仅在设备绑定关系中保留设备名称、型号等接入所必需的信息；（4）上述信息不共享给第三方，法律法规另有规定的除外。

**拒绝授权的影响与关闭方式。** 你可以拒绝上述任一权限，拒绝后仅**无法使用「扫码配网」**，不影响登录、对话、智能体等其他功能；你可以随时在系统「设置 → 应用 → 女娲 → 权限」中开启或关闭「位置信息」「附近的设备」权限，也可在 App 内「设置 → 隐私管理」查看当前授权状态。
